2026-10-12技术教程

Xiaohe v1.2.1 已正式发布。本次更新并非简单的版本迭代，而是围绕「连接稳不稳」和「协议全不全」两条主线展开的一次实质性升级——既修掉了几个长期影响日常使用的顽固问题，也把 AmneziaWG 的混淆能力补齐到了完整状态。

📌 本次更新要点速览

  • 内置 Aether Core 升级至官方 v2.1.0，并引入 SHA256 完整性校验
  • 修复系统代理写入死地址导致全部网页打不开的问题
  • 修复测速热切换引发的偶发断连，优化端点失效判定逻辑
  • 真正落地 AmneziaWG 伪造首包 I1，抗审查能力完整

🔧 核心变更

新版本将内置的 Aether Core 升级至官方 v2.1.0，并同步引入 SHA256 校验机制。这意味着核心组件在加载前会先经过完整性验证，来源可靠、内容未被篡改，从源头降低了核心被替换或损坏带来的风险。与此同时，本次还修复了一个影响面较广的问题：系统代理曾被写入死地址，导致浏览器打开任何网页都直接失败。该问题现已彻底解决，日常使用不再出现「连上了却打不开网页」的尴尬情况。

🔗 连接稳定性

开发团队针对「连接建立后进行测速热切换」所引发的偶发断连做了专项修复。此前在切换节点或重新测速的瞬间，连接可能出现短暂中断甚至彻底掉线，现在这一路径已被加固。

端点失效判定逻辑也一并优化：当某个端点被判定失效并移除时，系统会同步清除它的「最近可用」标记，避免后续连接反复回退到一个已经死掉的端点上。此外，当端点数据面出现失败时，客户端现在会自动回退到候选端点，而不是直接中断整条连接——用户感知到的只是短暂切换，而非掉线重连。

🚀 功能层面

v1.2.1 真正实现了 AmneziaWG 的伪造首包 I1 能力，补齐了 AWG 混淆的另一半。I1 是绕过 DPI 按「连接开头特征」判定封锁的关键机制：此前版本虽然实现了 junk 参数，但 I1 因未实现而被直接丢弃，混淆效果始终差一截。本次在设备层加入了 i1 支持，并提供 quic / dns / stun 等多种生成 profile，WireGuard 隧道由此具备完整的抗审查能力。

另外，v1.2.1 的发布构建已启用 -tags wgtun 编译标签，正式包内置原生 WireGuard 支持，无需用户额外配置。

✅ 实测兼容情况

  • WireGuard / Gool / MasqueH3：均正常工作
  • MasqueH2 / MIM：在当前网络环境下可能不可用，客户端中已如实标注
